FocusFlow settings

Hard mode only. No normal mode, study bypass or always-allow rule. Only verified study and tech content opens.

  1. Let AI verify the site once. The homepage and first study page are checked together. A dedicated study site then opens directly for 7 days. No manual educational allow-list.
  2. Read public metadata once. Titles and descriptions are checked without reading paragraphs, messages, editors or form values. Detected private pages are blocked without AI scanning.
  3. Decide locally first. Bundled text examples and hard rules handle clear pages. Local AI stays on for unclear pages; no paid API or hosting needed.
  4. Use AI only when needed. One request at a time. No startup warm-up or unused-link checks. Unverified pages stay blocked if AI fails.
  5. Remove distractions. Shorts, Reels and social feeds are blocked immediately. YouTube recommendations, comments and autoplay prompts are hidden.

Local AI is on by default, with a lightweight first check to avoid unnecessary inference. Hard mode is always on. No Hugging Face or hosted AI setup is required.

Set up Ollama for unclear pages
  1. Install Ollama from ollama.com/download.
  2. Download a small local model: ollama pull qwen3:1.7b. Set that exact model name below for lower latency. On Windows, scripts\windows\setup-ollama.cmd can do the setup.
  3. Keep Ollama running. If Test says 403, allow extensions and restart Ollama: OLLAMA_ORIGINS=chrome-extension://*,moz-extension://*

Both choices keep hard mode on. Startup warm-up and speculative link checks are disabled. Smaller AI models use less memory, but can be less accurate. Use Test a page to inspect decisions.
